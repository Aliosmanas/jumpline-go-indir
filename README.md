# JUMPLINE GO — indir

Android telefona kurmak için:

1. **[JumplineGo.apk'yı indir](https://github.com/Aliosmanas/jumpline-go-indir/releases/latest/download/JumplineGo.apk)**
2. İndirilen dosyaya dokun → "Bilinmeyen kaynaklardan yükleme"ye izin ver → **Yükle**.
3. Android 8.0 ve üstü gerekir.

Tüm sürümler: [Releases](https://github.com/Aliosmanas/jumpline-go-indir/releases)
